# TENSEI 0.6 — OCR, библиотека сканов, Легион и статистика

TENSEI — переносимая Windows-программа с локальным интерфейсом в браузере. Слева три раздела: **Распознавание фото**, **Легион · отчёты**, **Статистика**.

## Запуск и обновление

1. Скачайте ZIP главной ветки, распакуйте в папку вне OneDrive (рекомендуется внешний SSD).
2. При обновлении перенесите старую папку data целиком в новую, пока приложение закрыто. Там сохранены настройки, база ТС и предыдущие отчёты распознавания.
3. Запустите TENSEI.bat. Первый запуск требует подключения к интернету для портативного Node.js и npm-модулей.

## Распознавание фотографий и отдельная локальная библиотека

- При загрузке каждого фото TENSEI **сначала сохраняет оригинальные байты локально**, затем запускает Cloud.ru. Неудачное распознавание не удаляет фотографию.
- Для каждой фотографии создаётся собственный ID, превью, статус, отдельная таблица и архив изменений.
- Векторный SVG-индикатор показывает **реальный этап**: сохранение, подготовка, Cloud.ru, повторное чтение фрагментов, готовый результат. Таймер показывает время ожидания. Проценты — индикатор этапа, а не точное измерение готовности API.
- **Библиотека сканов** позволяет открыть отдельную фотографию и её таблицу, скачать оригинал, повторить ошибочную задачу, наблюдать за длительным вызовом даже после обновления страницы.
- Правки таблицы сохраняются именно в выбранном скане. Кнопка **«Очистить текущий вид»** не удаляет сканы и их уже сохранённые результаты. При новом фото предыдущая таблица не затирается.
- В новой папке data/scans находятся index.json (локальная база), папки с оригинальными изображениями original.bin, preview.jpg и result.json. При повторной обработке предыдущие результаты копируются в резервные JSON.
- Старые задачи из data/tasks.json + data/sources импортируются при первой загрузке библиотеки, если есть обработанный JPEG; пометка предупреждает, что прежняя версия не сохраняла исходные оригиналы.
- Чтобы перейти на подходящую модель Cloud.ru, нажмите «Проверить подключение». Если выбранной модели нет в каталоге, кнопка **«Выбрать доступную»** теперь также сохраняет выбор. Реальный вызов с вашим платным ключом не проверяется в GitHub CI.
- После ошибки авторизации, лимита или связи программа больше не делает лишние попытки чтения фрагментов; при пустом ответе может сделать повторные платные запросы. Читайте пояснения в настройках.

## «Легион · отчёты» — CSV с карьера

1. Импортируйте Excel со справочником «База ТС» или готовый старый отчёт «01.11 Хороль.xlsx».
2. Выберите CSV с карьера. Поддерживаются UTF-8 и Windows-1251.
3. Приложение сопоставляет машины с базой ТС, сохраняет все реальные рейсы и различает названия товаров, включая «Скала» и «СКАЛА +».
4. Автоматически создаются XLSX по каждому товару/дате и ZIP в reports/Легион. Базовый режим не требует Microsoft Excel или Cloud.ru.
5. Повторно импортированный **тот же файл** определяют по SHA-256: он не считается второй раз. Если вы загрузили два разных CSV с пересекающимися рейсами, их содержимое необходимо сверить самостоятельно.
6. Для всех полей добавлены пояснения об источнике данных. Если ещё не загружен CSV или база ТС, интерфейс объясняет причины нулевых показателей.

Формула образца сохранена: **тонны = нетто, кг / 1000**, а результат = **тонны / 1,55**. Это не физический расчёт тонно-километров.

Читайте [LEGION.md](LEGION.md).

## «Статистика» — 12 интерактивных векторных графиков

Линейная динамика и сравнение периодов, ТОП-10 машин, распределение товаров, календарь активности, загрузка автопарка, часы работы, категории аномалий, гистограмма веса, накопленный тоннаж, дни недели, заполненность и библиотека сканов. Фильтры по датам, товару, группировке и показателю. Нажатие на столбец автомобиля или календарную дату открывает соответствующие рейсы.

**Все показатели берутся из локальных CSV.** Если CSV ещё не импортирован, графики честно покажут отсутствие данных. Никакой вымышленной статистики. SVG-диаграммы работают без внешнего CDN.

Подробные источники и правила расчёта: [ANALYTICS.md](ANALYTICS.md).

## Приватность и хранение

По умолчанию папки data/ и reports/ находятся рядом с TENSEI и исключены из Git. **Важно: размещение программы внутри OneDrive означает, что фото, ФИО водителей, отчёты и незашифрованный API-ключ могут синхронизироваться в облако.** При обнаружении OneDrive интерфейс предупреждает об этом. Рекомендуется перенести TENSEI на отдельный SSD вне OneDrive. Для сохранения истории при обновлении копируйте data/ целиком.

Фотографии отправляются в Cloud.ru только для облачного OCR; CSV «Легион» обрабатываются локально. Дополнительные PaddleOCR, Chandra и MinerU требуют отдельных локальных сервисов и не устанавливаются вместе с BAT.

## Тесты

npm install
npm test

Проверки Windows/Linux покрывают разбор CSV, формулы XLSX, автоотчёты, историю сканов, сохранение после ошибки, статистику, SVG и пользовательский интерфейс. Реальное распознавание с вашим ключом Cloud.ru в CI не выполняется.
