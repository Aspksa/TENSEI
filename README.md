# TENSEI

Программа для распознавания фотографий рукописных журналов с помощью Cloud.ru и экспорта в Excel.

## Запуск на Windows 10/11 x64

1. Скачайте ZIP репозитория, распакуйте на внешний SSD.
2. Запустите `TENSEI.bat` — при первом запуске потребуются интернет и загрузка портативного Node.js и зависимостей.
3. Откройте http://127.0.0.1:57474.
4. Укажите API-ключ Cloud.ru и точный ID модели, поддерживающей фотографии.
5. Выберите JPG/PNG/WebP, нажмите «Распознать», проверьте таблицу и скачайте Excel.

Python и Docker не нужны. На ПК с запретами загрузки, запуска программ или другой архитектурой успех не гарантирован.

**Важно:** ключ находится в `data/settings.json`, исключён из Git, но пока не шифруется. Не передавайте файл другим людям. Фото отправляются провайдеру Cloud.ru. Таблица в браузере пока не сохраняется после перезапуска. Модель может ошибаться в рукописных цифрах, проверяйте оригинал.

Версия MVP. Работа с реальным API-ключом и на разных компьютерах ещё не проверена.
