# TENSEI 0.2 — интеллектуальный журнал

TENSEI считывает фотографии рукописных журналов (ТС, водитель, время, брутто/тара/нетто), помечает сомнительные значения и создаёт редактируемый файл Excel. Распознавание выполняется в Cloud.ru. Приложение работает локально на Windows, интерфейс открывается через браузер.

## Быстрый запуск на внешнем M.2

1. Скачайте архив репозитория, **распакуйте** в папку на внешнем SSD. Не запускайте BAT прямо внутри ZIP.
2. Запустите **TENSEI.bat**. На первом компьютере при первом запуске нужны интернет и право запускать локальные программы. Портативный Node.js и зависимости будут загружены внутрь папки проекта.
3. Дождитесь надписи `TENSEI_READY`. Браузер должен открыться сам; если не открылся, скопируйте локальный адрес из окна запуска.
4. В меню **Подключение ИИ** сохраните свой API-ключ Cloud.ru. Модель **Qwen3 VL 235B A22B Instruct** уже выбрана. По желанию доступны 30B и 8B. Модель должна быть доступна вашему аккаунту.
5. Перетащите фотографии на область загрузки. Нажмите **Распознать все**.
6. В разделе **Реестр** проверьте результаты, исправьте строки, отметьте ручную сверку с фотографией и скачайте Excel. В разделе **Проверка** собраны обнаруженные аномалии.

## Форматы

JPG/JPEG, PNG, WebP, TIFF/TIF, GIF (первый кадр), AVIF, BMP, SVG (безопасное подмножество). HEIC/HEIF зависит от поддержки кодека в сборке Sharp; если не поддерживается — конвертируйте в JPG/PNG. Другие форматы (например RAW камеры, PSD, PDF) **не поддерживаются автоматически**. Все поддерживаемые входы преобразуются в JPEG перед отправкой модели. Лимит — 20 МБ на изображение; очень большие изображения автоматически уменьшаются. Сохранение EXIF-ориентации предусмотрено.

## Проверки качества

- Отсутствующий номер автомобиля, время не в формате чч:мм, отсутствие веса.
- Нулевой или необычно большой вес, брутто меньше тары.
- Несоответствие между брутто, тарой и нетто.
- Возможные дубли строк — отмечаются, **но не удаляются**, потому что одна машина может делать несколько рейсов.
- Неуверенные ответы модели. Пользователь может подтвердить сверку с оригиналом.
- Перепроверяйте рукописные значения: проверка не гарантирует отсутствие ошибок OCR.

**Экспорт:** `TENSEI.xlsx`, лист «Реестр» с нетто в кг/тоннах и лист «Контроль» с итогами.

## Переносимость и ограничения

Запуск рассчитан на **Windows 10/11, x64 и ARM64**. Python, Docker и установка Node.js в систему не нужны. На новом ПК первый запуск может потребовать загрузку своей архитектурной версии Node.js и зависимостей; без доступа к nodejs.org/npmjs.org это не сработает. В некоторых организациях запуск программ с USB/SSD запрещён политиками защиты Windows. Для вызовов Cloud.ru интернет необходим. Сервер слушает только `127.0.0.1` и выбирает свободный порт автоматически.

## Данные и безопасность

Настройки находятся в `data/settings.json`, а черновик — в `data/draft.json` рядом с программой; каталог `data/` исключён из Git. **API-ключ хранится на диске без шифрования.** Не выкладывайте этот каталог в GitHub и не передавайте диск посторонним. Фотографии отправляются в Cloud.ru для распознавания, но отдельные фотографии в локальном архиве пока не сохраняются. Черновик с текстом восстанавливается после перезапуска.

## Проверки разработчика

После установки зависимостей выполните:

```
npm test
node --check server.mjs
node --check app.js
```

GitHub Actions проверяет проект на Windows и Linux. Реальное распознавание оплачивается Cloud.ru и требует действующего API-ключа; автоматические тесты не обращаются к платному API.
