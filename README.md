# TENSEI 0.3 — распознавание рукописных журналов

Локальное приложение для Windows 10/11 x64/ARM64: фотографии рукописных журналов → мультимодальная модель Cloud.ru → проверяемые строки → Excel. Интерфейс запускается в браузере, данные черновика хранятся рядом с программой.

## Как запустить

1. Скачайте ZIP с GitHub и **распакуйте** его в обычную папку или на внешний SSD.
2. Запустите `TENSEI.bat`. При первом запуске требуется интернет: программа загрузит портативный Node.js и необходимые библиотеки. Локальный адрес появится в окне после `TENSEI_READY`. Браузер обычно открывается автоматически.
3. **Шаг 1. Подключение Cloud.ru:** блок настроек находится **прямо вверху страницы**, раскрывается нажатием на заголовок и доступен даже без JavaScript-переключения вкладок. Укажите ключ и модель, нажмите **Сохранить**, затем **Проверить подключение**. Пустой ввод ключа не удаляет ранее сохранённый ключ.
4. **Шаг 2. Фотографии:** перетащите несколько JPG, PNG, WebP, GIF, BMP, TIFF, AVIF или SVG. Для HEIC/HEIF нужен поддерживаемый кодек.
5. Нажмите **Распознать**. Если модель недоступна, сообщение покажет причину, а файлы останутся в очереди для повтора.
6. **Шаг 3. Результат:** исправьте строки прямо в таблице, отметьте галочкой «Сверено» после сравнения с исходным фото, проверьте замечания и нажмите **Скачать Excel**. Черновик сохраняется автоматически.

## Проверка подключения

По умолчанию: `qwen/qwen3-vl-235b-a22b-instruct`. В списке есть и другие модели Qwen с поддержкой изображений. По кнопке «Проверить подключение» TENSEI читает список моделей, доступных через API вашему ключу. Наличие модели в списке ещё не гарантирует, что конкретная фотография будет успешно распознана.

Если фотографии дают **HTTP 404**, сначала проверьте доступ модели. После сохранения ключа нажмите «Проверить подключение» и выберите доступную модель, если предложена. Убедитесь, что ключ выпущен для сервиса Foundation Models. Функция резервной модели действует только при некоторых ошибках и может увеличить расходы.

## Файлы и ограничения

- `data/settings.json` — настройки, в том числе API-ключ **в незашифрованном виде**.
- `data/draft.json` — распознанные и исправленные строки; сохраняются локально, каталог исключён из Git.
- Фотографии отправляются в Cloud.ru; они не сохраняются в локальном архиве в этой версии.
- Размер одного файла — до 20 МБ; изображения автоматически преобразуются в JPEG. GIF/TIFF читаются как одна страница; PDF/RAW/PSD не поддерживаются.
- Для распознавания требуется интернет. Переносимый запуск может быть заблокирован корпоративными политиками Windows и не работает буквально на любом ПК.
- Точность на рукописных данных не гарантируется. Сомнительные цифры нужно сверять с оригиналом.

## Тестирование разработчика

```bash
npm install
npm test
```

Проверки включают разбор ответов Cloud.ru, изображения, арифметические аномалии, HTTP API и браузерные DOM-действия с настройками/таблицей. CI проверяет Windows и Linux, но запрос к платному Cloud.ru с реальным ключом в автоматических тестах не выполняется.
