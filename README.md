# TENSEI 0.5 — фотографии и автоматические отчёты с карьера

TENSEI — локальное браузерное приложение для Windows 10/11 x64/ARM64, которое принимает фотографии рукописных журналов, передаёт изображения в Cloud.ru, предлагает проверку данных и создаёт Excel.

## Новый раздел «Легион · отчёты»

В левом меню появился автономный процесс **CSV с карьера → проверка машин → отдельные Excel по товарам и датам → ZIP**. Поддерживается Windows-1251 и UTF-8. Марка/модель и водитель подтягиваются из локального справочника «База ТС»; отсутствующие данные обозначаются «НЕТ В БАЗЕ». Повторные рейсы не удаляются, вес переводится в тонны, расчёт выполняется строго по указанной формуле **тонны / 1,55**. Готовые XLSX сохраняются в папку reports/Легион рядом с TENSEI. **Для этого раздела не нужен Microsoft Excel или Cloud.ru.**

Настройка, мастер-файл и важные ограничения описаны в [LEGION.md](LEGION.md).

## Переносимая установка без сложных действий

Для Windows 10/11 x64 запустите **`TENSEI.bat`** из распакованной папки. Установщик проверит права записи, свободное место, Node.js и npm-зависимости, а при сбое установки зависимостей постарается восстановить предыдущий комплект. Для переноса базы и отчётов предусмотрены **`TENSEI_Backup.bat`** и **`TENSEI_Restore.bat`** (ZIP с SHA-256 и без перезаписи существующих файлов). После онлайн-установки можно создать **`TENSEI_OfflinePack.bat`** для другого Windows-компьютера той же архитектуры CPU без интернета. Подробности и ограничения: [PORTABLE_INSTALLER.md](PORTABLE_INSTALLER.md).

## Проверка целостности данных и поиск ошибок

После обновления TENSEI доступен **`TENSEI_Audit.bat`**: локальная проверка индекса CSV, всех доступных импортов, исходников фото, истории OCR и черновика. Она не изменяет базу, не требует Python или Cloud.ru и не выводит личные данные. В главном интерфейсе также откройте **«Не запускается? Проверить состояние TENSEI»**. Высокоприоритетные замечания требуют резервной копии и проверки оператором; отсутствующие рейсы никогда не вносятся в журнал автоматически. Сводка исправленных ограничений и открытых рисков — [DEEP_AUDIT_2026-11-05.md](DEEP_AUDIT_2026-11-05.md).

## Запуск и обновление

1. Скачайте ZIP репозитория, распакуйте на компьютер или внешний SSD и запустите **TENSEI.bat**. При первом запуске нужен интернет для установки портативного Node.js и npm-пакетов. Python для базового режима не требуется.
2. Откройте локальный адрес, выведенный в окне `TENSEI_READY`.
3. В настройках укажите API-ключ Cloud.ru и выберите модель. По умолчанию **Qwen3 VL 235B A22B Instruct**; для переключения доступны другие модели с поддержкой изображений. Нажмите «Сохранить» и «Проверить подключение».
4. Добавьте JPG, PNG, WebP, TIFF, GIF, BMP, AVIF или SVG (HEIC/HEIF — при наличии кодека). Перед отправкой показывается локальная диагностика разрешения, яркости, контраста и возможной смазанности.
5. Выберите шаблон журнала и нажмите «Распознать». После этого сверяйте результаты с фотографией и скачивайте Excel.

## Что нового в версии 0.4

- **Обработка пустого ответа Cloud.ru:** при `content=null`, пустом тексте или незавершённом ответе приложение показывает `finish_reason`, делает не больше одного повторного запроса с большим лимитом и, при включённой настройке, пробует резервную модель. Если и это не помогло, можно включить ограниченное повторное чтение увеличенных частей. **Повторные запросы платные** и не гарантируют результат.
- **Фото до OCR:** коррекция ориентации из EXIF, адаптивное улучшение освещения/контраста и предупреждения о низком разрешении, пересвете, слабом контрасте и потенциальной смазанности. Автоматическая коррекция перспективы и геометрических деформаций всего изображения без PaddleOCR пока не реализована.
- **Разметка таблицы:** при отдельно установленном локальном **PaddleOCR PP-StructureV3** получает ориентировочные координаты ячеек/строк. Это необязательная функция: основной TENSEI работает и без него. PaddleOCR может выполнять собственное выравнивание и исправление геометрии *внутри своего пайплайна*, но преобразованное изображение пока не заменяет исходное фото для Qwen.
- **Чтение увеличенных фрагментов:** при неудаче на всей странице Qwen получает верхнюю/нижнюю часть или до четырёх геометрических областей, если их обнаружил PaddleOCR. Эти результаты всегда помечаются для ручной сверки.
- **Подсветка источника:** сохранённые подготовленные JPEG лежат локально в `data/sources`. Нажатие на строку реестра показывает фотографию и предположительную рамку строки, **только когда координаты есть**. Рамки могут быть неточными.
- **Независимая проверка Chandra OCR 2:** подключается только при отдельно запущенном локальном vLLM/OpenAI-совместимом сервере Chandra; сравнение по наличию весовых чисел — лишь подсказка, а не точное выравнивание ячеек. Разночтения не перезаписывают данные автоматически.
- **Умная очередь и MinerU Tasks 4.1:** задания TENSEI сохраняются локально в `data/tasks.json` (статус, ошибка, кэш успешных фотографий). Дополнительно, при включении и отдельно запущенном локальном MinerU 4.1, TENSEI умеет отправить JPEG в настоящий `/v1/tasks`, загрузить недостающий файл через `PUT` и проверить `/v1/tasks/{task_id}`. Результаты MinerU ещё **не импортируются в Excel и не подменяют Qwen**; интеграция экспериментальная.
- **Шаблоны:** встроенные «Журнал весовой» и «Универсальная таблица», плюс пользовательские названия/порядок колонок в `data/templates.json`. Они улучшают подсказку модели, но пока не задают точные координаты столбцов.
- **Точность и аномалии:** неуверенные веса и время, дубли, несоответствие брутто-тары-нетто отмечаются и никогда не удаляются автоматически.

## Необязательный локальный PaddleOCR

Это расширенный режим для мощного компьютера или отдельного OCR-сервера, **не ставится автоматически вместе с BAT**:

1. Установите совместимый Python 3.11 и PaddlePaddle (CPU/GPU) по инструкции разработчика.
2. Создайте окружение Python и установите `pip install -r scripts/paddle-requirements.txt`.
3. Запустите `python scripts/paddle_service.py` — поднимется **127.0.0.1:8765**, при первом запуске могут загрузиться веса моделей.
4. В TENSEI в дополнительных настройках включите **PaddleOCR** и сохраните.

Оценка совместимости и производительности зависит от CPU/GPU и версии PaddlePaddle; не все Windows ARM64 поддерживаются. Возвращаются приблизительные координаты ячеек, не гарантированное восстановление структуры каждой рукописной таблицы.

## Необязательный Chandra OCR 2

Запустите собственный OpenAI-совместимый сервер Chandra через vLLM на **127.0.0.1:8000/v1**, модель с ID `chandra` (или предоставьте `TENSEI_CHANDRA_URL` в окружении Windows). В дополнительных настройках включите Chandra OCR. TENSEI не скачивает и не запускает её автоматически. **Внимательно проверьте модифицированную лицензию OpenRAIL-M для весов Chandra 2**, особенно если используете систему коммерчески. Chandra может потребовать мощный GPU.

## Необязательный MinerU Tasks 4.1

Для интеграции нужна отдельно установленная **MinerU 4.1**, как локальный сервер, не обязательная для основного BAT:

1. Установите MinerU в совместимом Python 3.11–3.14 согласно официальному руководству.
2. Запустите API, например: `mineru-kit api-server --host 127.0.0.1 --port 8766 --tier basic`.
3. В расширенных настройках TENSEI включите MinerU и сохраните.
4. После успешного распознавания Qwen создаётся дополнительная задача разбора документа в MinerU. Откройте **История задач → Статус MinerU**, чтобы увидеть состояние. Это отдельная ресурсоёмкая операция.

Текущая интеграция рассчитана на **локальный self-hosted** API по HTTP, по умолчанию `127.0.0.1:8766`. Иные адреса блокируются намеренно для защиты файлов. При необходимости можно задать `TENSEI_MINERU_URL` и `TENSEI_MINERU_KEY` в локальном окружении. Поддерживаются создание/передача/опрос, но не автоматическая загрузка ZIP-результатов. Официальная лицензия MinerU добавляет условия к Apache 2.0.

## Данные и безопасность

- `data/settings.json`: ключ Cloud.ru и настройки **не шифруются**, но исключены из Git.
- `data/draft.json`: строки реестра; `data/tasks.json`: статусы и кэш результатов; `data/templates.json`: шаблоны; `data/sources/`: фотографии в JPEG, подготовленные для модели. Все эти файлы локальные.
- Внешняя модель Cloud.ru получает фотографии, когда запускается распознавание. API и страница доступны только по `127.0.0.1`.
- Не передавайте папку `data` посторонним и не синхронизируйте её в публичный репозиторий.
- Один файл до 20 МБ. PDF/RAW/PSD ещё не поддерживаются.
- Нажмите «Распознать заново» для обхода кэша **осознанно**, поскольку это создаёт новые платные запросы.
- Пользователь обязан сверять веса и номера с оригиналом. Результаты облачных и OCR-моделей могут отличаться.

## Разработка и CI

```bash
npm install
npm test
```

GitHub CI проверяет Windows и Linux, включая модули Cloud.ru (с мок-ответами), обработку изображений, шаблоны, HTTP-сервер и интерфейс. **Реальное распознавание вашим API-ключом в CI не запускается**, а доступность Chandra и PaddleOCR требует отдельно настроенных сервисов.
