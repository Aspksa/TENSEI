# TENSEI · Легион: импорт, контроль, Excel

Обновлён рабочий процесс «Легиона» с сохранением существующего CSV (UTF-8/UTF-16LE/Windows-1251) и привычных Excel по дате и товару.

## Операторский сценарий

1. Загрузите один CSV или одновременно от 2 до 8 CSV. Один файл должен быть до 8 МБ в пакетном режиме; исходный старый API для одного CSV принимает до 15 МБ.
2. TENSEI локально проверит обязательные заголовки, даты, вес, номера, известность машин и дубли с одинаковыми датой/временем/товаром/госномером/№ ТН/нетто. Никакой OCR или платной модели в «Легионе» не используется.
3. Если есть критические замечания (неизвестная модель/водитель, дубли, некорректная арифметика, превышение 45 т), система **не создаёт итоговый Excel и ZIP**. Оператор исправляет справочник ТС или исходный CSV и загружает файл снова. Данные не исправляются предположениями.
4. Некорректные CSV-строки показываются отдельно. Старый режим **ручного** пропуска таких строк остаётся доступным только после явного подтверждения, если при этом нет других критических проблем. Автогенерация в таком случае никогда не запускается.
5. При успешной проверке TENSEI сверит число рейсов и общую сумму кг исходного CSV с группами по дате/товару, затем с итогами созданных файлов; формирует ZIP.

## Отчёты

В ZIP по-прежнему есть **старые файлы XLSX по каждому дню и товару**, с прежними листами «Отчёт»/«Контроль», прежними колонками и формулами. Появляется дополнительный **Легион_сводный_*.xlsx** с листами:

- По дням
- По месяцам
- По автомобилям
- По товарам («Скала» и «СКАЛА +» остаются разными)
- Контроль ошибок
- Параметры (включая точный коэффициент)
- Сравнение версий (сравнение с последним ранее загруженным CSV, показывает количество рейсов, сумму кг, добавленные/удалённые ключи поездок)

Применяется существующая формула `тонны / коэффициент`, как в прежнем шаблоне. Это **не стандартные физические тонно-километры** (в обычном случае т·км = тонны × расстояние). Коэффициент по умолчанию — 1,55, и он записывается в историю и каждый сводный Excel.

## Справочник ТС

Нормализуются госномера, включая похожие латинские и кириллические буквы. Известные марка и водитель берутся только из сохранённой базы; неизвестные сведения требуют исправления оператором. Редактор базы и импорт мастер XLSX доступны в раскрывающемся блоке.

## Ограничения

- Проверка дубликатов использует точный ключ, а не вероятностный поиск «похожих» поездок. Разные номера талонов или нетто требуют отдельного разбирательства.
- Система не удаляет дубли автоматически.
- При массовом импорте и генерации действует ограничение в 12 000 рейсов на пакет, максимум 80 групп отчётов.
- Сводный лист «Сравнение версий» сопоставляет записи по точным данным и отчёты по суммам. Он не утверждает, что похожие поездки одинаковы.
- Реальный контроль не подменяется статусом «CSV прочитан»: завершённая загрузка ещё не значит, что отчёт допустим.

Для проверки запускайте `npm test` и CI Windows/Linux.
