# TENSEI: упрощённый рабочий экран и автоматизация

Главный сценарий: **загрузить фото → увидеть этапы по каждому файлу → сверить данные → получить Excel**.

## Основное меню

- Главная — фото, очередь, 5 статусов, 309 необязательных шуточных фраз.
- Проверка и реестр — таблица весов, сомнительные строки, подтверждения и Excel.
- Аналитика — рейсы, тоннаж, машины, расходы Cloud.ru; открытая страница обновляется каждые 45 секунд.
- Настройки — Cloud.ru, режим и дополнительные локальные OCR-модули.
- «Дополнительно» — ранее существующий Легион/CSV. Ничего не удалено.

## Автоматизировано

- Подготовка изображения и проверка качества сохраняются.
- Новый профиль **Авто** предпочитает Qwen VL 30B с ограничением платных HTTP-вызовов. Конкретная модель должна быть доступна по вашему ключу Cloud.ru. Каскад на более крупную модель применяется только в пределах лимита и только к проблемным строкам с известными координатами.
- При включённой настройке «Автоматическая локальная проверка» TENSEI пытается получить сетку таблицы (OpenCV) и отдельный OCR (PP-OCRv6) от установленного локального сервиса; при недоступности предупреждает и продолжает облачный сценарий. Наличие локального OCR **ещё не означает**, что облачный запрос отменится: локальный результат пока служит диагностикой.
- Точное кеширование повторных фото, обнаружение визуально похожих фото, проверка веса и номеров в подтверждённом справочнике, ограниченная выборочная перепроверка, последовательная очередь, архивация результатов существовали ранее и сохраняются.
- После каждого изменения проверяются подтверждения и замечания. Если включено «Автоматически скачать Excel», то браузер запускает экспорт **только после ручного подтверждения всех строк** и отсутствия обнаруженных проблем. Непроверенные веса не попадают в автоматически выгруженный файл.
- Этапы, история задач, количество платных вызовов и токены отображаются отдельно от шуток, которые можно отключить.

## Ограничения

- Начальный шаблон для фото — весовой журнал, его можно поменять в свёрнутом блоке. Тип документа определяют по распознанным строкам для отчёта; полностью надёжного *выбора шаблона до распознавания* ещё нет.
- Локальные OpenCV/PaddleOCR устанавливаются отдельно, а точность рукописных цифр проверяется на собственных снимках.
- Список «на проверку» — проверка по текущим правилам, а не абсолютная гарантия отсутствия ошибок.
- Стоимость в рублях не показывается без верифицированных тарифов. Лимит облачных запросов — ограничение числа HTTP-вызовов, не денежных затрат.
- Нельзя считать результат достоверным только по индикатору 100%: он означает завершение задания, не проверку оператором.
