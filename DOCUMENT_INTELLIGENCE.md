# TENSEI: документный интеллект и автоматизация (экспериментальные модули)

План внедрения шести направлений: предобработка / OCR / понимание / оценка уверенности / память / оркестрация.

## Что есть
- PP-StructureV3 (отдельный локальный сервис): координаты таблиц.
- Дополнительные localhost endpoints PP-OCRv6 `/ocr` и PaddleOCR-VL `/vl`; можно включить в расширенных настройках. Система показывает диагностические сведения, **не подставляет** непроверенные результаты OCR вместо весов.
- `document-intelligence.mjs`: эвристическая классификация журнала и детерминированная оценка риска для каждой строки. Оценка основана на правилах, **это не вероятность правильного распознавания**.
- `approved-memory.json`: список подтверждённых автомобилей и водителей. Запись только через `POST /api/approved-memory` с `confirmed: true`, чтение `GET /api/approved-memory`. Никакого автоматического обучения без подтверждения; подсказки не меняют оригинал.
- Однопоточная очередь запросов на сервере для `POST /api/recognize`, чтобы одновременные загрузки не перегружали локальные OCR-модели. Состояние задач продолжает сохраняться в `data/tasks.json`.
- `GET /api/ai-monitor`: число обработанных фото, вызовов Cloud.ru и доступный расход токенов; денежная стоимость не рассчитывается без подтверждённых тарифов.
- Каждый отчёт `data/photo-reports/<id>.json` содержит классификацию, оценки по строкам, подсказки памяти, а также необязательные сведения PP-OCRv6 и PaddleOCR-VL.

## Как включить
Установите локальные зависимости PaddleOCR отдельно (см. README и scripts/paddle-requirements.txt). Запустите `scripts/paddle_service.py` на `127.0.0.1:8765`; откройте «Дополнительные режимы распознавания» и включите локальные модули. Первый запуск может загружать веса и требовать значительную RAM / GPU. Без установленного локального сервера TENSEI выдаст предупреждение и продолжит базовую работу.

## Ограничения
- OpenCV-перспектива как отдельный обязательный модуль пока не интегрирована. У PP-OCRv6 и PaddleOCR-VL включены собственные локальные инструменты коррекции геометрии; исходное фото в Cloud.ru не изменяется на основании их предобработки.
- Нет гарантированной zero-cloud обработки: локальные результаты пока диагностические, а основной реестр формирует Cloud.ru.
- Автоматическая обработка поступающих файлов из наблюдаемой папки пока не включена: текущая очередь обслуживает запросы интерфейса, не выполняет фонового наблюдения за файловой системой.
- Риск-оценка не калибрована на реальных фотографиях карьера.
- Проверка на настоящей установленной PaddleOCR-VL и реальном Cloud.ru обязательна до применения без ручной проверки.
